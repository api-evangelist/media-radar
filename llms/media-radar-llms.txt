# MediaRadar

> MediaRadar (incorporating the data and capabilities of Vivvix) is a marketing and
> advertising intelligence platform that tracks advertising investment, creative and
> brand activity across streaming and linear TV, digital and programmatic, social,
> retail media, out-of-home, radio, podcast and print. It serves brands, agencies,
> publishers, platforms and consultancies with competitive, commercial, creative,
> market and political ad intelligence. MediaRadar delivers its data through a web
> UX, data feeds and a client REST API.

## Important for agents

- **There is no public API contract.** MediaRadar publishes no OpenAPI, Swagger,
  GraphQL, AsyncAPI, MCP or A2A artifact on any host it controls. Do not attempt to
  synthesize one.
- **The API is customer-gated.** The MediaRadar Client API Portal
  (https://api-portal.mediaradar.com/) is an Azure API Management developer portal.
  Its API and product catalog is not exposed to anonymous visitors: the portal's own
  management endpoint returns an empty collection unauthenticated
  (`GET /developer/apis?api-version=2022-04-01-preview` -> `{"value":[],"nextLink":null}`).
  Endpoints, schemas, quotas and examples are visible only after client sign-in.
- **Authentication is a per-client API Key**, presented as an Azure API Management
  subscription-key request header. There is no OAuth 2.0 authorization server; the
  portal's OAuth flow is account registration for the portal itself.
- **API base host**: `https://api.mediaradar.com` — confirmed live as an Azure API
  Management gateway by anonymous probe (it answers unrouted requests with APIM's own
  `{ "statusCode": 404, "message": "Resource not found" }` envelope and reports a
  Premium APIM instance in Azure East US 2 at `/internal-status-0123456789abcdef`).
  Individual operation paths are not published. `https://api.vivvix.com` fronts the
  same gateway.
- **No SDK, no CLI, no MCP server, no Postman collection, no status page, no
  changelog, no published rate limits and no published pricing.** These are verified
  absences, probed 2026-08-12 — not gaps in this profile.

## APIs
